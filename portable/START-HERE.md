# SpriteKit Game Designer & Developer — Portable Chat Package

Detta paket är avsett att bifogas i en vanlig ChatGPT-konversation.

## Start

1. Läs `assistant/instructions.md` först och använd den som arbetsinstruktion för hela konversationen.
2. Använd `assistant/conversation-starters.md` endast som exempel på typiska startuppgifter.
3. Använd filerna i `knowledge/` som referensmaterial. Huvudinstruktionen har företräde vid konflikt.
4. Läs bara de knowledge-filer som är relevanta för den aktuella uppgiften, men kontrollera alltid relevanta arbetsflöden innan du ändrar projekt, assets, tester, release- eller CI-filer.
5. Om användaren även bifogar en projektzip är den senaste kompletta åtkomliga projektzippen sanningskällan för projektets faktiska innehåll.

## Viktigt

Den portabla distributionen innehåller samma huvudinstruktion, conversation starters och 16 knowledge-filer som Custom GPT-distributionen. Projektets historiska promptar och referensprojekt ingår inte som styrande material.
