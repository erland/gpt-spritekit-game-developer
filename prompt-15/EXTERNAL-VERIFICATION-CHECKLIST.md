# Extern verifieringschecklista

## GPT Preview

- [ ] GPT-konfiguration skapad från `config/`.
- [ ] Alla 15 kunskapsfiler uppladdade.
- [ ] Kodtolkare/dataanalys aktiverat.
- [ ] Webbsökning aktiverad.
- [ ] Bildgenerering aktiverad.
- [ ] T01–T04, T05A–T05E och T06–T15 körda och dokumenterade.
- [ ] Zip med ändrad fixture kan hämtas och öppnas.
- [ ] Bildgenerering följer assetspecifikation och eftergranskning.

## Xcode och macOS

- [ ] Projektet öppnas utan migreringsfel.
- [ ] macOS-target bygger.
- [ ] XCTest körs och är godkänt.
- [ ] Tangentbordsadapter fungerar som utvecklingshjälp.

## tvOS och Apple TV

- [ ] tvOS-target bygger.
- [ ] Appen startar i simulator eller på Apple TV.
- [ ] Controller identifieras.
- [ ] Analog dead zone och rörelse fungerar.
- [ ] Paus och återupptagning fungerar.
- [ ] Controllerfrånkoppling pausas och förklaras tydligt.
- [ ] Text, fokus och säkra kanter är läsbara på TV-avstånd.
